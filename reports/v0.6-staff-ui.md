**Atualização de 19/11/2026:** este texto registra o checkpoint inicial de consulta. Este checkpoint acrescenta uma área de consulta. A v0.5 permanece aberta; edição de staff, conversão dos atributos e conclusão da v0.6 continuam pendentes.

## Código integrado

- Abertura carrega e indexa os perfis de staff no núcleo Rust. O resumo inclui a contagem; erros desse domínio recebem contexto “Falha ao ler staff”.
- Comandos `search_staff` e `staff_detail` registrados no Tauri. Resultados paginados de50; busca por nome, UID, clube, seleção e função, com normalização de acentos.
- Navegação Staff mostra funções, vínculos, nascimento/idade, reputação e CA/PA próprias de staff. Valores brutos permanecem em diagnóstico expansível, sem controles de edição.
- Jogador/staff tem botão para abrir seu perfil de jogador. Ao consultar um perfil com alterações pendentes de jogador, o Rust projeta a transação completa antes de resolver novamente o staff; dados pessoais compartilhados refletem o plano.
- Navegação pede descarte de rascunho antes de trocar para staff; cancelar mantém o jogador e aceitar restaura os valores preparados no plano. Abrir outro save limpa os estados de staff.

## Como reproduzir o teste de frontend

```powershell
npm run build:ui
node tools/preview-desktop.js
```

Em outro terminal:

```powershell
playwright-cli -s=staff-ui open --browser=chrome
playwright-cli -s=staff-ui run-code --filename=tools/check-staff-ui.playwright.js
playwright-cli -s=staff-ui --raw eval 'JSON.stringify(window.__staffUiResult)'
playwright-cli -s=staff-ui close
```

O CLI pode devolver controle enquanto os handlers de diálogo terminam; o resultado final fica em `window.__staffUiResult`. O servidor expõe apenas os três assets compilados em127.0.0.1:4173. Encerrá-lo com Ctrl+C depois da verificação.
